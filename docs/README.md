# GDS ERP Documentation

This documentation captures the planning foundation for the Global Display Systems (GDS) ERP before application implementation begins.

## Directories

- `requirements/` — Product scope, requirements, constraints, and unresolved questions.
- `workflows/` — Documented business and system workflows.
- `data-dictionary/` — Agreed definitions for data entities, fields, and terms.
- `permissions/` — Roles, access levels, and authorization requirements.
- `architecture/` — Technical architecture, boundaries, and design documentation.
- `decisions/` — Architecture Decision Records (ADRs) and their maintenance guidance.
- `testing/` — Test strategy, acceptance criteria, and validation plans.
- `recovery/` — Backup, restoration, continuity, and disaster-recovery plans.
