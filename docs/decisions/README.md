# Architecture Decision Records

Architecture Decision Records (ADRs) document significant technical decisions after they are agreed.

## Numbering

- Use four-digit, sequential numbers beginning with `0001`.
- Name files `NNNN-short-title.md`.
- Never reuse a number, including when an ADR is superseded.

## Maintenance

- Create an ADR only after a decision is approved.
- Keep accepted ADRs as a historical record.
- Record the status of each ADR clearly.
- When a decision changes, create a new ADR and link the superseded and superseding records.
- Amend an accepted ADR only to correct minor errors or clarify wording without changing the decision.
